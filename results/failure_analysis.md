## A와 B의 실패 성격 차이

- **A (RAG)**: 정보가 없어서 틀림. 주문 데이터에 접근할 수 없고, 문서 검색은 하지만 상태(승인/폐기/미검증)를 가리지 않음. → 지식 검색·보안(인젝션)·연동 문제
- **B (Agent)**: 정보에 접근할 수 있는데 LLM이 제대로 안 씀. 도구를 안 부르거나, 엉뚱한 인자로 부르거나, 조회 결과를 잘못 해석함. → 의도 분석·시스템 실행·신뢰성·보안(권한) 문제

## 아직 확인 안 한 것

- **비결정성 (시스템 실행)**: 1회만 실행해서 같은 질문의 반복 결과 차이는 미확인
- **보안 테스트셋**: `eval_security.jsonl`은 이번 데이터에 없음 (README에는 20개로 명시)
- 채점은 키워드 기반이라 표현이 다른 정답을 놓칠 수 있음 (예: PUB-012 A는 "3,000원"만 빠져 실패)
